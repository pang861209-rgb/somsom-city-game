# 당근빌라 방범대 — 에셋 생산 명세서 v1.0 (나노바나나 작업지시서)

> 기획서 v0.3 §10의 실행 버전. 나노바나나(Gemini) 연결 후 이 문서 순서대로 생성하면

## 0. 공통 규칙 (프로덕션 가이드 검증 레시피 준수)

- **입력**: 해당 캐릭터의 **작가 원본 시트 이미지 첨부 필수** (텍스트 묘사만 쓰면 그림체 변형됨).
- **공통 프롬프트 접두**: "2등신(머리:몸=1:1) 치비로, 그림체 동일(가는 손그림 라인, 첨부 시트에서 색 샘플링, 동일한 얼굴), 흰 배경, 텍스트 금지, 정체성 포인트 과장 유지(끼토 귀=몸통 길이·진주 목걸이 / 보늘 둥근 실루엣·반감긴 눈 / 미개 분홍 리본·6다리 / 람다 몸집만 한 꼬리·앞니 / 라칠친 둥근 안경·쪽머리·보라 카디건 / 북거씨 네발·터틀넥·직사각 안경)"
- **모델**: gemini-3.1-flash-image, 비율 1:1 (배경류만 3:4 세로).
- **후처리(엔진에서 자동)**: 플러드필 흰배경 키잉 + trimCanvas 여백 제거 → **흰 옷·흰자 유지되니 배경만 순백으로**.
- **멀티샷 운영**: 표기된 컷수만큼 생성 → 1차 스크리닝 3기준(①라인 굵기가 기존 SD와 일치 ②확정 팔레트 준수 ③해당 표시 크기로 축소했을 때 실루엣 판독) → 후보 2~3개 작가 검수. 탈락샷은 `rejected/`에 보관(시즌 스킨 후보).
- **모션 구현 방식**: 게임2에서 검증된 **2프레임 스왑**(A/B 교대) + 엔진 보간(숨쉬기·스쿼시·반동). 생성은 정지 프레임만 — 프레임 B는 항상 "A를 첨부하고 자세만 바꿔달라"로 생성해 동일성 유지.
- **저장 위치·네이밍**: `assets/defense/` 아래, `<분류>_<이름>_<상태>.png` (아래 표의 파일명 그대로).

## 1. 캐릭터 타워 (P0 — M1 필수) — 6캐릭터 × 5프레임 = 30장 (컷수 각 4~6)

기존 SD는 낙엽피하기용 정면 대기 자세라 타워로 쓰면 어색함(유저 피드백). **타워 전용 3/4 정면 포즈로 전부 재생성.**
프레임 구성은 전 캐릭터 공통, 액션 내용만 캐릭터별로 다르다. 발끝 하단 정렬 필수(뱃지·그림자 정렬 기준).

| 프레임 | 파일명 접미 | 용도 (엔진 동작) |
|---|---|---|
| 대기 A | `_idle_a` | 기본. 엔진이 A/B 0.6초 교대 + 숨쉬기 보간 |
| 대기 B | `_idle_b` | A와 같은 포즈에서 디테일만 변화(귀·꼬리·더듬이 위치) |
| 액션 | `_act` | 공격/작동 순간 0.2초 스왑 + 반동 |
| 승리 | `_win` | 처치(중화) 순간 0.7초 |
| 피격 | `_hit` | 당근빌라 뚫린 순간 1초 (전원 동시) |

### 캐릭터별 모션 컨셉 (프롬프트에 그대로 사용)

| 캐릭터 | 대기 A/B | 액션 (`_act`) | 승리 (`_win`) | 피격 (`_hit`) | 컷수 |
|---|---|---|---|---|---|
| **미개** ⚡속사 | 앞다리 들고 두리번 / 더듬이 방향만 바뀜 | 입 크게 벌리고 몸을 앞으로 날리며 낚아채기 | 더듬이가 하트 모양, 배 통통 | 더듬이 꼬불꼬불, 눈 그렁 | 각 5 |
| **끼토** 🐰감속 | 귀 쫑긋 세우고 경계 / 귀가 좌우로 기울어 레이더처럼 | 두 귀를 안테나처럼 쭉 뻗고 파동(엔진이 링 이펙트 추가) | 안도의 미소, 가슴 쓸어내림 | 귀 잡고 "으아아" 멘붕(시그니처) | 각 5 |
| **보늘** 🛡️바리케이드 | 경로에 벌러덩 누워 하품 / 눈 반쯤 감김 | 등을 웅크려 몸으로 막기(단단한 느낌) | 누운 채 엄지척, 과자 하나 입에 | 살짝 찡그림 "아야. 뭐, 한 대 정도야" | 각 5 |
| **람다** 🧲자원 | 꼬리 S자로 살랑, 주머니 뒤적 / 꼬리 방향 반대 | 도토리를 번쩍 들어 올리며 반짝이는 눈 | 꼬리 크게 흔들며 도토리 두 개 들기 | 꼬리 축 처짐, 주머니 뒤집힘 | 각 5 |
| **북거씨** 🐢광역 | 네발로 낮게 엎드려 향수병 곁에 / 코 벌름 | 향수병 분무기를 꾹 눌러 미스트 분사(분사 방향 위쪽) | 만족스럽게 코로 향 음미 | 등딱지에 살짝 움츠림 | 각 5 |
| **라칠친** 🔄은행 줍기 | 바구니 들고 허리 편 채 두리번 / 안경 고쳐 씀 | 허리 굽혀 은행을 집게로 콕 집기 | 바구니 들어 보이며 "그래~" 웃음 | 허리 두드리며 "아이구야" | 각 5 |

### 스킬 발동 컷 (P1 — M2) — 6장, 컷수 각 4
`skill_<이름>.png` — 스킬 버튼 아이콘 + 발동 컷인(화면 하단 얼굴 컷) 겸용. 정사각 얼굴 클로즈업:
미개 폭식(볼 빵빵) / 끼토 귀 잡고 집중 / 보늘 쿨쿨 zzz / 람다 도토리 쏟아내기 / 북거씨 '바다' 향 분사 / 라칠친 호루라기.

## 6. 생성 순서 & 물량 요약

| 순번 | 묶음 | 장수(채택 기준) | 생성 컷수(멀티샷) |
|---|---|---|---|
| ① P0 캐릭터 타워 5프레임 | 30장 | ≈150컷 |
| ② P0 골칫거리 6종+보스 | 24장 | ≈40컷 |
| ③ P0 배경(필드 3종)+구조물 6종 | 9장 | ≈35컷 |
| ④ P1 스킬 컷·UI·이펙트 | 15장 | ≈35컷 |
| 합계 | **78장** | **≈260컷** |

- **최소 세트로 먼저 보고 싶으면**: ①에서 미개·끼토만(10장) + ② 꼬릿·먼지(6장) + ③ 골목 바닥 1종 + 블록·경로 타일 = **20장이면 현재 M0.6이 완전히 새 옷을 입는다.** 이걸 1차 배치로 추천.
- 생성 완료본은 `assets/defense/`에 커밋만 해주면 게임 연결은 내가 처리 (파일명만 이 문서대로).
