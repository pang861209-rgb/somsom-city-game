# 당근빌라 방범대 — 에셋 생산 명세서 v1.1 (나노바나나 작업지시서)

> v1.0(개별 생성 260컷)은 표시 크기(30~76px) 대비 낭비 — **총 생성 약 40컷으로 축소.**
> 절감 원칙 2가지:
> **① 시트 생성** — 한 장에 여러 포즈/여러 종을 나란히 (작가 검수 승인된 `SD_시안_v1.png` 6종 한 장 방식).
>   같은 생성 안에서 나오므로 그림체 통일에도 유리. 슬라이스·키잉은 엔진 쪽에서 자동 처리(파일 그대로 커밋만).
> **② 앵커 → 파생** — 스타일을 정하는 앵커 컷만 멀티샷(3컷), 파생은 채택샷을 첨부하고 1~2컷.
> 모션 B프레임·중화 표정은 엔진 보간(스쿼시·페이드·바운스)으로 대체 — 생성 안 함.

## 0. 공통 규칙

- **입력**: 작가 원본 시트 이미지 첨부 필수. 파생 생성 시 **직전 채택샷도 함께 첨부**.
- **공통 프롬프트 접두**: "2등신(1:1) 치비, 그림체 동일(가는 손그림 라인·첨부 시트 색 샘플링·동일 얼굴), 순백 배경, 텍스트 금지, 정체성 포인트 과장 유지(끼토 긴 귀·진주 목걸이 / 보늘 둥근 실루엣 / 미개 분홍 리본·6다리 / 람다 큰 꼬리·앞니 / 라칠친 둥근 안경·보라 카디건 / 북거씨 네발·터틀넥)"
- **시트 요청 문구**: "가로 일렬, 균등 간격, 포즈 사이 충분한 여백, 서로 겹치지 않게" — 슬라이스는 투명 열 기준 자동 분할.
- 모델 gemini-3.1-flash-image. 캐릭터 시트 비율 16:9 또는 2:1(가로), 배경 3:4(세로), 나머지 1:1.
- 저장: `assets/defense/` 아래 아래 표 파일명 그대로(시트는 통짜로 커밋 — 슬라이스는 클로드가 처리).
