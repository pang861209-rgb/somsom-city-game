# 서비스 기획서 v0.3 — 솜솜시티: 당근빌라 방범대 (개발용 상세판)

> **한 줄 정의**: 솜솜시티 주민들로 '방범대'를 꾸려 골목 타일 위 설치 블록에 배치하고,
> 대나무숲 빌라에서 흘러오는 꼬릿 구름과 가을 골칫거리를 향수·빗자루로 **중화하며 당근 빌라를 지키는**
> 타일 그리드 캐주얼 디펜스. **제목 확정: '솜솜시티: 당근빌라 방범대'**.

> 이 문서 하나로 개발 착수가 가능한 것을 목표로 한다(수치·맵·스키마·에셋 프롬프트 포함).
> v0.2에서의 변경: ① 제목 확정 ② 세계관 신장 기반 캐릭터 크기 시스템 ③ 타일 그리드 맵(설치 블록 분리, 경로 길이 확보)
> ④ 전 수치 테이블화 ⑤ 나노바나나 멀티샷 에셋 생산 계획.

## 1. 서비스 개요 (v0.2 승계, 요약)

- **목적**: 수익화 없음. IP 게임 3호 — 긴 세션의 계획형 재미, 캐릭터 '조합'으로 관계성 노출, 단추 수집 메타로 재방문.
- **플랫폼**: 모바일 웹(HTML5 단일 파일), 솜솜시티 허브 통합. 세로 420×680 논리 해상도, DPR 3배.
- **포지션**: 무스토리. 세계관은 소재로만. 톤 가드레일 — *무찌르지 않는다, 치운다* (중화 시 향기 파티클, 은행은 바구니로).
- **1판 목표**: 3~4분. 재플레이 동기 = 3★ 카운터 조합 퍼즐 + 단추 + 무한 모드 랭킹.

## 3. 맵 시스템 — 타일 그리드

### 3.1 그리드 정의
- 필드 영역: 420×520 (y=80~600). **타일 52px, 8열(A~H)×10행(1~10)**. 상단 HUD 80px, 하단 카드 독 80px.
- 배경(골목 사진)은 필드 뒤에 깔고 크림 워시 α0.45 디밍(게임1 전례) — 타일·유닛 가독성 우선.

### 3.2 타일 타입
| 기호 | 타입 | 규칙 |
|---|---|---|
| `E` | 입구 | 골칫거리 스폰. 대나무숲 빌라 방향 연출 |
| `V` | 당근 빌라(출구) | 도달 시 쾌적도 -1. 빌라 외관 스프라이트 |
| `=` | 경로 | 골칫거리 이동. 설치 불가. 보늘 바리케이드만 설치 가능 |
| `#` | **설치 블록** | 주민 설치 가능한 전용 블록(밝은 테두리+모서리 나사 연출로 명확히 구분) |
| `b` | 틈새 블록(반 칸) | **미개 전용** 설치 칸 — 크기 시스템의 게임화 |
| `T` | 은행나무 | 설치 불가. **'바람 부는 웨이브'(스테이지별 지정)에만 6초 간격 유한 버스트(3~4회)로 인접 경로에 은행 스폰** — M1 검증: 무한 스폰은 웨이브 교착·과난이도 유발로 금지 |
| `.` | 장식 | 설치 불가(화분·가판대 등 소품) |

- 경로 길이 기준: S1 16타일 → S8 26타일+ (짧아 보임 문제의 구조적 해결 — 경로가 필드를 2~3회 왕복).
- 설치 블록 수: **스테이지당 10~14개(+틈새 1~2개)** — M0 유저 테스트 반영(8개는 "자리가 한정적" 체감). 퍼즐은 블록 희소성이 아니라 **자리의 질**(경로 커버리지 차이)에서 나온다. 후반 스테이지일수록 블록은 많되 프라임 스팟(경로 2면 인접)을 줄여 난이도 유지.

### 3.3 스테이지 맵 8장 (확정 시안 — 8×10 그리드)

**⚠ 설계 변경 (유저 플레이 피드백, M3)**: 지정 설치 블록 방식 폐지 → **자유 배치**(경로·입구·빌라·은행나무 제외 전 타일 설치 가능, 보늘만 경로 전용). "왜 여기만 되지?"라는 제약감이 재미를 깎는다는 피드백 반영 — 퍼즐성은 블록 희소성이 아니라 경로 굴곡의 커버리지 차이에서 나온다. 미개 전용 틈새 블록도 함께 폐지. 스테이지당 웨이브 수 4~5 → 6~8로 연장(플레이 시간 목표 3~4분 충족). 아래 블록 규칙·맵의 `#`/`b` 표기는 이전 설계의 기록으로 남긴다.

## 13.5 챕터 2+ 확장 템플릿 (스테이지 증설 절차)
