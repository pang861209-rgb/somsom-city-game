# 서비스 기획서 v0.2 — 솜솜시티: 골목 대작전 (배치형 캐주얼 디펜스)

> **한 줄 정의**: 솜솜시티 주민을 골목 곳곳에 배치해, 대나무숲 빌라에서 흘러오는 악취 구름과
> 가을 골칫거리들을 향수 미스트·빗자루로 **중화하며 당근 빌라를 지키는** 배치형 캐주얼 디펜스.
> 가칭 **'솜솜시티: 골목 대작전'** (대안: 냄새 대소동 / 당근빌라 방범대).

> v1.0(디펜스타워, 낙엽 군단 침공 컨셉)을 전면 개정.
> 개정 근거: IP 세계관 문서·게임 프로덕션 가이드·서비스 기획서 v0.1(은행 주의보)의 확정 원칙 반영.

## 1. 서비스 개요

- **목적**: 수익화 없음(가이드 원칙 유지). 솜솜시티 IP 게임 3호로서 게임1(은행 주의보, 반사신경)·게임2(달려라 솜솜시티, 러너)가 못 하는 것을 담당 —
  **① 긴 세션(체류시간)·계획형 재미 ② 캐릭터 '조합'으로 IP의 관계성(케미)을 보여주기 ③ 수집 메타(단추)로 재방문 동기.**
- **타깃**: 게임1·2 기존 플레이어(허브 유입), 작가 SNS 팔로워, 캐주얼 디펜스 입문자.
- **플랫폼**: 모바일 웹(HTML5) 우선, 솜솜시티 허브에 3번째 메뉴로 통합. 링크 공유 즉시 플레이.
- **포지션**: 무스토리. 세계관은 소재로만(악취 구름, 향수, 단추, 은행, 잎사귀 우산). 컷씬·대사 진행 없음, 캐릭터 말풍선 리액션만(게임1 방식).
- **포트폴리오 관점**: 게임1·2의 캐릭터 픽률/기록 데이터와 교차 분석해 IP 사업(굿즈·콘텐츠)용 캐릭터 선호 데이터를 확장한다.

## 2. 핵심 루프

**스테이지 선택 → 배치·강화(도토리) → 웨이브 방어 → 별점·단추 획득 → 주민 영구 강화 → 다음 스테이지 / 무한 모드**

- 1판 목표 시간: 3~4분 (게임1: 30초~2분 → 디펜스는 한 단계 긴 세션 담당).
- 재플레이 동기 = 3★ 도전(카운터 조합 퍼즐) + 단추 수집(영구 강화) + 무한 모드 랭킹.
- **패배 조건**: 당근 빌라 쾌적도(❤10) 소진. 골칫거리가 빌라에 도달할 때마다 -1.
- **별점**: 남은 쾌적도 10=3★ / 6+=2★ / 클리어=1★. 별점 합계로 단추 획득.

## 3. 게임 룰 — "무찌르지 않는다, 치운다"

톤 가드레일: 적은 '악당'이 아니라 **미워할 수 없는 골칫거리**. 처치 연출 없음 —
중화되면 뿅! 하고 향기 파티클로 사라지고, 은행은 주워서 바구니로 들어간다. (작가 톤 확인 필요 항목 → §11)

- **조작 3가지가 전부** (한 손, 터치 홀드/탭만): 카드 드래그 배치 · 배치된 주민 탭(강화/회수) · 스킬 버튼 탭.
- **골칫거리 (적) — 적 1종 = 카운터 주민 1명 원칙**:

| 골칫거리 | 출처(세계관) | 특성 | 카운터 |
|---|---|---|---|
| 꼬릿 구름 | 대나무숲 빌라 쓰레기장 | 기본. 느리고 물량형 | 북거씨 미스트 |
| 굴러오는 은행 | 은행나무 골목 | 빠르게 굴러옴, 밟으면 냄새 | 라칠친(주워서 점수화) |
| 부스러기 떼 | 보늘의 과자 | 죽으면 4마리로 분열 | 미개(먹어치움) |
| 먼지 뭉치 | 골목 구석 | 빠름, 작음 | 미개·끼토 슬로우 |
| 젖은 낙엽 더미 | 비 온 다음 날 | 느린 탱커 | 보늘 바리케이드 |
| 둥둥 꽃가루 | 계절 소재 | 비행 — 바리케이드 통과 | 북거씨(광역), 미개 |
| **왕꼬릿 구름 (보스)** | 4·8스테이지 | 분열 + 경로 변경 | 조합 종합 시험 |

- **난이도 원칙** (게임1 밸런스 원칙 승계): 첫 3스테이지는 아무 조합으로도 클리어 가능, 3★만 카운터 조합을 요구. 생존 강화 능력은 비용/속도로 상쇄.

## 4. 주민 = 타워 (6인 + 확장 파이프라인)

게임1에서 검증된 능력 정체성을 1:1 계승 — 기존 플레이어가 설명 없이 이해하는 것이 목표.
상세 스탯은 '캐릭터 게임 프로필' DB에 행 추가로 관리(가이드의 신규 캐릭터 파이프라인 준용).

| 주민 | 게임1 능력 | 디펜스 역할 | 비용 | 액티브 스킬(쿨타임) |
|---|---|---|---|---|
| 미개 ⚡ | 초고속·소형 | **속사** — 부스러기·먼지를 빠르게 먹어치움 | 80 | 5초 공속 2배 |
| 끼토 🐰 | 귀 슬로우 | **감속** — 귀 레이더 범위 내 골칫거리 -30% | 100 | 전장 3초 슬로우 |
| 보늘 🛡️ | 맷집 | **바리케이드** — 경로에 눕기. 체력 보유, 통과 저지 | 120 | 체력 회복 + 낮잠(5초 도발) |
| 람다 🧲 | 줍줍 자석 | **자원** — 도토리 생산 + 주변 처치 보상 +25% | 140 | 즉시 도토리 +150 |
| 북거씨 🐢 | 등딱지 쉘터 | **광역 중화** — 향수 미스트 분사(느리지만 범위 큼) + 인접 버프 | 150 | '바다' 향 전체 분사(전장 광역) |
| 라칠친 🔄 | 룰 반전 | **은행 줍기** — 은행을 피해 없이 주워 점수·도토리로 전환 | 160 | 은행 줍기 크루 호출(친구들 등장) |

- **판 내 강화**: 탭 → 도토리로 Lv1→3 (비용 = 배치가의 80%→150%, 환급 70%).
- **영구 강화(메타)**: 별점으로 얻는 **단추**로 주민별 등급업. 나이테존 컨셉 차용 — 같은 주민을 오래 쓸수록(누적 판수) 강화 할인. 저장은 localStorage.
- **확장 캐릭터 파이프라인** (유저 반응 후): 캐릭터보드 → 프로필 DB 1행 → 에셋 1세트. 후보: 라칠친의 은행 줍기 친구들, 대나무숲 빌라 주민(화해 컨셉).

## 5. 맵 · 스테이지 — "맵은 작게, 정보는 크게"

- **1화면 고정** (420×680, 스크롤·줌 없음). 필드는 화면의 ~60%만 사용, 나머지는 HUD·카드에 양보.
  게임1의 배경 디밍(α0.45)을 필드에 동일 적용 — 배경보다 골칫거리·주민 가독성 우선.
- **경로**: 화면 위(대나무숲 빌라 방향) → 아래(당근 빌라). 슬롯 6~8개 지정 배치(자유 배치 없음 — 오배치 스트레스 제거).
- **분량 (소프트 스타트)**: 챕터 1 "골목 어귀" **8스테이지** + 무한 모드.
  - 1~2 튜토리얼(미개·끼토) · 3~5 주민 1명씩 해금 · 6~7 조합 시험 · 4/8 보스.
- **무한 모드**: 고정 시드 웨이브 — 게임1 Firebase 랭킹 인프라 재사용(새 컬렉션 `defense_scores`, 규칙 추가 필요 — 게임2 때와 동일 이슈 선반영).
- **시즌 확장** (저비용, 가이드 방식): 골칫거리·배경 스킨 교체형 — 봄 꽃가루, 여름 장마(잎사귀 우산 소재), 겨울 눈뭉치. 룰 동일.

## 6. 화면 흐름 (5화면)

1. **타이틀**: 로고 + 시작. 단체 컷.
2. **스테이지 선택**: 노드는 **크게(터치 타깃 64px+)**, 별점·해금 상태·다음 해금 주민 예고.
3. **인게임**: 상단 HUD(웨이브·도토리·쾌적도·2배속) / 필드 / 하단 주민 카드 6장 + 스킬 버튼.
4. **결과**: 별점, 획득 단추, 최고 콤보성 지표, 캐릭터 리액션 말풍선, 📸 자랑하기(게임1 공유 카드 재사용).
5. **주민 강화(로비)**: 단추 소지량, 주민별 등급·다음 강화 효과. 게임1 카드형 선택 화면 문법 재사용.

## 7. 아트 · 사운드

- **에셋 재사용**: SD 6종·소품(은행·도토리·가지)·골목 배경 완료분 그대로. 흰배경 키잉(테두리 플러드필) 파이프라인 유지.
- **신규 에셋 (백로그와 합치)**: 향수병·미스트(가이드 4장 미착수분과 동일), 악취 구름 표정 시트, 단추 아이콘 세트, 타워 배치 포즈(기존 표정 스와프 파이프라인 활용).
- **컬러**: 프로덕션 가이드 3장 확정 팔레트 사용(외곽선 #222220). UI는 게임1 스티커풍(종이 배경, 검정 2px 테두리+오프셋 그림자) 유지.
- **IP 고유 표현**: 끼토 귀 쭈뼛(보스 접근 경고), 미개 더듬이 하트(처치 시), 라칠친 "그래~" 보이스 — 가이드 1순위 '주스' 원칙.
- **접근성**: 색약 모드(골칫거리 형태 구분 강화), 한손 조작, 햅틱 토글(게임1 미구현분 여기서 해소).

## 8. 기술 설계

- 단일 HTML + Canvas 2D, 의존성 없음, GitHub Pages (게임1·2 컨벤션).
- **오브젝트 풀링 필수**(가이드 2순위 — 웨이브당 골칫거리 40+ 동시).
- **밸런스 선언형 분리**: 타워/골칫거리/웨이브 스탯을 JS 테이블 → 추후 리모트 컨피그 전환 대비(핫픽스용).
- 저장: localStorage(진행도·별점·단추·주민 등급) / Firebase(무한 모드 랭킹).
- 성능: 미드폰 60fps, 첫 실행→첫 플레이 10초 이내, 저사양 모드(파티클 감소).

## 9. 애널리틱스 (밸런스 패치 전제 조건 — 가이드 3순위)

수집 이벤트: 스테이지 시작/클리어/포기(이탈 퍼널), 별점 분포, 주민 픽률·조합(동시 배치 세트), 판당 평균 길이, 무한 모드 도달 웨이브.
게임1·2 픽률과 교차: 캐릭터 선호가 장르 따라 달라지는지 → IP 사업 데이터.

## 10. Soft KPI

- 스테이지 3 도달률 70%+ (튜토리얼 이탈 감시)
- 챕터 클리어율 30%+, 클리어 유저의 3★ 재도전율 50%+
- 1인당 판수 5판+, 평균 세션 8분+
- 조합 다양성: 최다 조합 점유율 40% 미만 (특정 조합 고착 = 밸런스 신호)
- 정성: "귀엽다/조합 찾는 재미" 언급, 단추·나이테존 소재 반응
