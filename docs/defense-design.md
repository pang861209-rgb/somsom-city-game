# 솜솜시티 디펜스타워 — 게임 기획안 (v1.0)

> 「솜솜시티 낙엽피하기」의 세계관과 캐릭터를 그대로 이어받는 두 번째 게임.
> 이번에는 피하지 않는다. **골목을 지킨다.**

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 | 솜솜시티 디펜스타워 (가제) |
| 장르 | 캐주얼 타워 디펜스 |
| 플랫폼 | 모바일 웹 우선 (HTML5 Canvas 단일 파일), PC 브라우저 겸용 |
| 세션 길이 | 스테이지당 3~5분, 총 1회 플레이 10~20분 |
| 타깃 | 낙엽피하기 유저 + 캐주얼 디펜스 입문자 |
| 조작 | 터치(탭·드래그)만으로 전 기능 조작, 마우스 겸용 |
| 아트 | 기존 SD 캐릭터·소품 에셋 재활용 + 타워/적 신규 에셋 |

### 핵심 컨셉
- **"주민이 곧 타워"** — 솜솜시티 주민 6명을 골목 곳곳에 배치해 낙엽 군단을 막는다.
- 낙엽피하기에서 각 캐릭터가 가졌던 개성(슬로우·맷집·초고속·자석·반전·등딱지)을 타워 능력으로 그대로 계승해, 기존 유저가 "아 이 캐릭터니까 이런 타워구나"를 즉시 이해하게 한다.
- 재화도 세계관 그대로: **도토리**(기본 재화), **황금잎**(프리미엄 재화), **은행**(위험하지만 고가치).

---

## 2. 스토리 · 세계관

> 가을이 깊어진 솜솜시티. 어느 날 밤, 거대한 태풍 "갈바람"이 몰고 온
> **낙엽 군단**이 골목을 점령하기 시작했다. 목표는 시티 한가운데의
> **도토리 창고** — 주민들의 겨울 식량이다.
>
> "가, 가스 불은 잠갔고... 이번엔 도망치지 않아!" (끼토)
>
> 여섯 주민이 골목 어귀에 나섰다. 도토리 창고를 지켜라!

- 최종 보스는 태풍의 핵 **"갈바람"**. 스테이지를 거치며 낙엽 군단의 정체(사실은 겨울을 나려는 낙엽들의 오해)가 조금씩 드러나고, 최종 스테이지 클리어 시 화해 엔딩으로 마무리 — 기존 게임의 순한 톤 유지.

---

## 3. 코어 게임 루프

```
스테이지 시작 → 웨이브 예고 확인 → 도토리로 주민(타워) 배치/강화
  → 웨이브 전투 (적 처치 시 도토리 획득) → 웨이브 사이 재정비
  → 최종 웨이브 클리어 → 별점 정산 → 황금잎 획득 → 다음 스테이지
```

- **패배 조건**: 도토리 창고 내구도(라이프 10) 소진.
- **별점(1~3★)**: 남은 창고 내구도 기준 (10 = 3★ / 6 이상 = 2★ / 클리어 = 1★).
- **황금잎**: 별점·업적으로 획득, 주민 영구 강화(레벨업)에 사용.

---

## 4. 주민 = 타워 6종

낙엽피하기의 능력을 1:1로 계승한다. 배치 비용은 도토리.

| 주민 | 계승 능력 | 타워 역할 | 비용 | 공격 방식 |
|---|---|---|---|---|
| **끼토** 🐰 | 귀 슬로우 | **감속 타워** | 100 | 범위 내 적 이동속도 -30%. 공격력은 없지만 모든 조합의 핵심 |
| **미개** ⚡ | 초고속 | **속사 타워** | 80 | 단일 대상 저데미지 초고속 연사. 최저가 기본 딜러 |
| **보늘** 🛡️ | 맷집 | **바리케이드** | 120 | 경로 위에 직접 배치하는 근접 타워. 적을 멈춰 세우고 받아친다. 체력 보유, 파괴 시 재배치 |
| **라칠친 할머니** 🔄 | 룰 반전 (은행=점수) | **은행 투척 타워** | 160 | 곡사 광역 스플래시 + 은행 냄새로 잠시 공격력 감소 디버프 |
| **람다** 🧲 | 줍줍 자석 | **자원 타워** | 140 | 공격 없음. 주기적으로 도토리 생산 + 주변 타워의 처치 보상 +25% |
| **북거씨** 🐢 | 등딱지 쉘터 | **버프 타워** | 150 | 주변 타워 공격속도 +20%, 보늘 바리케이드에 보호막 부여. 느리지만 든든한 지원 |

### 강화 체계
- **스테이지 내 강화**: 배치된 타워를 탭 → 도토리로 Lv1→Lv3 (수치 상승 + 3레벨에서 외형 변화).
- **영구 강화**: 로비에서 황금잎로 주민별 등급업 (기존 게임 캐릭터 카드 UI 재활용).
- **액티브 스킬 (캐릭터별 1개, 쿨타임제)** — 낙엽피하기의 "더블터치 스킬" 감각 계승:
  - 끼토: 전장 전체 3초 슬로우 / 미개: 5초 공속 2배 / 보늘: 체력 완전 회복
  - 라칠친: 은행 폭격 (지정 지점 광역) / 람다: 즉시 도토리 +150 / 북거씨: 전체 타워 무적 3초

## 5. 적 — 낙엽 군단

| 적 | 원형 에셋 | 특성 |
|---|---|---|
| 낙엽졸병 | 낙엽 | 기본. 느리고 약함, 물량으로 승부 |
| 마른가지 | prop_branch | 빠르고 가벼움. 미개(속사)로 카운터 |
| 도토리도둑 | prop_acorn | 처치 못 하고 통과당하면 도토리를 훔쳐감 (라이프 대신 재화 피해) |
| 은행폭탄병 | prop_ginkgo | 처치 시 폭발해 주변 타워 잠시 기절 — 원거리 처치 유도 |
| 낙엽더미 | 신규 | 느린 탱커. 죽으면 낙엽졸병 4마리로 분열 |
| 회오리바람 | 신규 | 비행. 보늘 바리케이드를 무시하고 지나감 — 대공 배치 강제 |
| **보스: 갈바람** | 신규 | 5스테이지마다 등장. 이동 경로를 스스로 바꾸는 패턴 |

설계 원칙: **적 1종 = 카운터 주민 1명**. 모든 적은 특정 주민 조합으로 명확히 대응되게 해서 "누굴 어디에 놓을까"가 퍼즐이 되게 한다.

## 6. 맵 · 스테이지

- **배경**: 기존 골목 배경(bg_alley) 톤의 세로형 맵. 모바일 세로 화면(420×680 기준) 최적화.
- **경로**: 화면 상단(골목 입구) → 하단(도토리 창고)로 흐르는 고정 경로. 스테이지가 진행되며 갈래길 2개 → 3개로 확장.
- **배치 슬롯**: 경로 옆 지정 슬롯 방식(자유 배치 아님) — 터치 조작에서 오배치 스트레스 제거.
- **분량 (1차 출시)**: 챕터 1 "골목 어귀" 10스테이지 + 무한 모드 1종.
  - 1~2: 튜토리얼 (끼토·미개만) / 3~6: 주민 1명씩 해금 / 7~9: 조합 시험 / 10: 갈바람 보스전.
- **무한 모드**: 웨이브 무한, 최고 기록 = 낙엽피하기처럼 로컬 랭킹 저장.

## 7. UI / UX

- **조작**: 하단 주민 카드에서 슬롯으로 드래그해 배치 → 배치된 타워 탭 = 강화/판매 팝업 → 스킬 버튼 탭 = 액티브 발동. 3가지 제스처가 전부.
- **웨이브 예고**: 다음 웨이브 적 구성을 상단에 아이콘으로 미리 표시 (전략 준비 시간 제공).
- **배속**: 1x / 2x 토글.
- **햅틱**: 기존 게임의 iOS 햅틱 우회 코드 재사용 — 적 처치·창고 피격 시 진동.
- **대사**: 배치·스킬·승리·패배 시 캐릭터 말풍선 (기존 intro/hit/record/lose 대사 톤 유지, 신규 작성).
- **아트 디렉션**: 기존 팔레트 유지 — 배경 `#221E18`, 포인트 골드 `#F2C14B`, 크림 `#EFE7D6`. 폰트 Black Han Sans(제목) / Gowun Dodum(본문).

## 8. 밸런스 초안 (튜닝 기준값)

| 항목 | 값 |
|---|---|
| 시작 도토리 | 200 |
| 낙엽졸병 | HP 20 / 속도 1.0 / 처치 보상 5 |
| 미개 Lv1 | DPS 10 / 사거리 짧음 |
| 라칠친 Lv1 | 광역 15 / 3초당 1발 |
| 타워 강화 비용 | 배치가의 80% → 150% |
| 판매 환급 | 투자액의 70% |
| 웨이브 수 | 스테이지당 5~8웨이브 |

원칙: **첫 3스테이지는 아무 조합으로도 클리어 가능**, 3★는 카운터 조합을 요구. 숫자는 프로토타입에서 플레이 테스트로 조정.

## 9. 기술 설계

- 기존과 동일한 **단일 HTML + Canvas 2D, 의존성 없음** 구조 유지 (GitHub Pages 배포).
- 해상도: 420×680 논리 좌표 + DPR 3배 대응 (기존 코드 컨벤션 계승).
- 저장: `localStorage` — 스테이지 진행도, 별점, 황금잎, 주민 영구 레벨, 무한 모드 기록.
- 데이터 구조: 타워/적/웨이브를 전부 선언형 테이블(JS 객체)로 분리 → 밸런스 수정이 코드 수정 없이 가능하게.
- 성능 목표: 미드레인지 폰에서 적 60마리 + 투사체 동시 표시 60fps.
