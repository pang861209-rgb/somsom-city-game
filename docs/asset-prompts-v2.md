# 당근빌라 방범대 — 이미지 백로그 프롬프트 팩 v2.0 (모션·진화·시즌)

> **목적:** R4에서 코드로 못 푼 백로그 — ① 주민 모션 프레임 확장 ② 골칫거리 걷기 프레임 ③ 진화 A/B 전용 외형 ④ (선택) 봄 시즌 스킨 — 을 **이미지 생성이 가능한 환경(맥)** 에서 그대로 실행할 수 있게 미리 써 둔 팩.
> v1.0(`asset-prompts.md`)은 R1 제작 기록으로 보존. **v2는 현재 `assets/defense/`에 채택된 시트를 스타일 앵커로 씀** — 작가 원화 재첨부 불필요(채택 시트가 이미 원화 기준으로 통과한 결과물).
>
> **토큰 원칙 — 무조건 멀티샷:** 컷 하나에 4~8칸을 가로 일렬로 담는다. 컷당 후보 **1장**만 뽑고, 슬라이스 게이트 실패(칸 수 불일치·겹침·바닥선)일 때만 재생성 1장. 총 예산 **18컷 + 예비 4컷 = 22컷 이내**.

## 0. 파이프라인 규격 (프롬프트가 지켜야 하는 이유)

엔진의 `sliceSheet(canvas, want)`는 **흰 배경을 BFS로 키잉한 뒤, 완전히 투명한 세로 열을 경계로 자른다.** 그래서 아래를 어기면 슬라이스가 깨진다.

| 규칙 | 어기면 생기는 일 (실제 사고 사례) |
|---|---|
| 순백(#FFFFFF) 배경, **바닥선·그림자·배경 소품 금지** | 바닥선이 칸을 전부 이어 붙여 1덩어리로 슬라이스됨 (R1 앵커 1안) |
| 칸 사이 여백 ≥ 캐릭터 폭의 25%, **서로 절대 겹치지 않게** | 붙은 칸은 "가장 넓은 덩어리 반갈" 폴백으로 잘려 캐릭터가 두 동강 (람다·라칠친 1차) |
| **칸당 캐릭터 1명(1마리)** | 북거씨 2안 3번 칸에 거북 두 마리가 합쳐짐 |
| **텍스트·의성어·워터마크 금지** ("zzz", "아이구야" 포함) | 라칠친 2안에 글자 "아이구야"가 들어가 폐기 |
| 모든 칸에서 캐릭터 **크기 동일·발끝 하단 정렬** | 엔진이 발끝 피벗으로 회전·스쿼시하므로 칸마다 크기가 다르면 애니메이션이 튄다 |
| 첨부 시트와 **완전히 동일한 신체 구조** (미개=곤충, 북거씨=4족, 보늘=통통) | 의인화·날씬화 재발 방지 — 프롬프트마다 명시 |
| 칸 순서는 프롬프트에 쓴 번호 그대로 **왼쪽→오른쪽** | 순서가 바뀌면 코드 매핑(`SHEET_POSE`)이 어긋남 → 순서 틀린 컷은 채택 불가 |

비율: **4칸 = 16:9**, **6칸 = 21:9**, **8칸 = 21:9** (칸당 ~250px, 적 스프라이트는 화면에서 26~44px이므로 충분).

**공통 접두 문구 (모든 프롬프트 맨 앞에 그대로 붙임):**
```
첨부된 시트와 완전히 동일한 캐릭터·그림체·선 굵기·채색·신체 구조. 가로 일렬 N칸, 균등 간격, 칸 사이 여백 충분, 서로 절대 겹치지 않게, 칸당 캐릭터 1명, 모든 칸 동일 크기, 발끝 하단 정렬. 순백 배경, 바닥선·그림자·소품 배경 금지, 텍스트·의성어 금지.
```

**실행 명령 (원격/맥 공통, `scratchpad/gen.py`):**
```
python3 gen.py <출력.png> <비율> <프롬프트.txt> <첨부1.png> [첨부2.png ...]
```
