# 당근빌라 방범대 — 정식 발매 디밸롭 기획서 v1.0

> 전제: 현재 빌드는 **MVP(검증용)**이다. 이 문서는 "실제 발매해서 소비자에게 만족을 주는 수준"까지의
> 격차를 냉정하게 진단하고, 시니어 게임 기획 관점의 디밸롭 계획을 정의한다.

---

## 0. 냉정한 진단 — MVP의 현주소

시중 디펜스(킹덤러쉬, 블룬스 TD, 랜덤 다이스, 국내 방치·캐주얼 디펜스군)와 정면 비교:

| 축 | 시중 상위 디펜스 | 우리 MVP | 갭 |
|---|---|---|---|
| 전략 깊이 | 타워 분기 진화(4~5티어), 영웅, 타겟 지정, 수십 개 업그레이드 트리 | 6타워 × 3레벨 일직선 | **심각** — 2판이면 조합 공간 소진 |
| 콘텐츠 볼륨 | 40~80 스테이지 + 하드/영웅 난이도 + 이벤트 맵 | 4스테이지 + 무한 1개 | **심각** — 총 플레이 20분 |
| 판 안의 손맛 | 웨이브 중 실시간 의사결정 밀도 높음(스킬 조준, 영웅 컨트롤, 긴급 판단) | 배치 후 관전 + 버튼 스킬 4~6개 | **크다** — 중반부터 손이 놂 |
| 성장 실감 | 진화 시 외형·능력이 극적으로 변함, 수집(유물·스킨) | 등급당 스탯 +8% (체감 미미) | **크다** |
| 아트·연출 | 전용 타워 아트, 공격 모션, 맵 테마별 완전 교체 | 타 게임 SD 유용 + 코드 드로잉 | **크다** (에셋 명세 v1.1로 해소 예정) |
| 리텐션 장치 | 데일리·주간 챌린지·시즌 이벤트·랭킹 | 허브 데일리 미션 1개 + 로컬 무한 기록 | **크다** |
| 상성의 가독성 | 적 등장 시 카운터 힌트, 도감, 명확한 아이콘 언어 | 텍스트 한 줄 (이번에 추가) | 중간 |

**결론**: 지금 구조로는 못 이긴다 — 맞다. 다만 이길 전장을 고르는 것이 먼저다.

## 1. 포지셔닝 — 어디서 이길 것인가

킹덤러쉬를 볼륨으로 이기려는 순간 진다(수십 인월 아트·개발). 우리가 이길 수 있는 전장 3개:

1. **IP 애착**: 시중 디펜스의 타워는 '유닛'이지만 우리 타워는 '아는 캐릭터'다. 캐릭터의 성격·관계가 시스템으로 드러날수록(케미 시너지, 대사, 진화 서사) 대체 불가가 된다.
2. **한입 세션 완성도**: 설치 없는 웹, 3~5분 1판, 폰에서 완벽한 조작. "쉬는 시간에 한 판"의 밀도로 승부.
3. **발견의 재미 밀도**: 볼륨 대신 **조합·시너지·기믹의 발견**이 매 스테이지 1개 이상 나오게 설계 — "이 조합 되네?"의 순간을 짧은 콘텐츠 안에 압축.

> 목표 문장: **"가장 큰 디펜스가 아니라, 가장 아끼게 되는 디펜스."**
> 단, 아래 필러들의 '깊이 최소선'은 시중 캐주얼 디펜스 수준을 반드시 넘는다.

## 2. 디밸롭 5대 필러

### P1. 전략 깊이 — "조합 공간을 12배로"

- **분기 진화 (핵심)**: Lv3 도달 시 주민별 **2갈래 진화** 선택 → 실질 타워 12종.
  | 주민 | 진화 A | 진화 B |
  |---|---|---|
  | 미개 | **개미 행렬** — 분신 2기가 좌우 칸에 소환(광역 물량전) | **저격 더듬이** — 사거리 3.5타일, 마킹된 적 2배(단일 저격) |
  | 끼토 | **골목 방송** — 감속장이 경로 전체의 30%로 확대 | **집중 마킹** — 마킹 +40%, 마킹된 적 처치 시 도토리 2배 |
  | 보늘 | **철벽 낮잠** — HP 3배, 주변 타워 피해 대신 받기 | **탄성 배치기** — 접촉 적을 2타일 뒤로 튕겨냄(경로 되돌리기) |
  | 람다 | **단추 공방** — 도토리 대신 매 판 단추 조각 생산(메타 직결) | **투자 귀재** — 이자: 보유 도토리의 3%/웨이브 |
  | 북거씨 | **'바다' 조향사** — 미스트가 지속 장판화(도트) | **향수 폭격** — 주기 2배 느리게, 피해 4배 광역 |
  | 라칠친 | **줍기 명장** — 모든 소형 적도 회수 대상 | **은행 폭탄** — 회수한 은행을 최전방에 투척(광역 피해) |
- **케미 시너지 (IP 시스템화)**: 세계관 관계 기반 인접 보너스, 발동 시 두 캐릭터 말풍선 합.
  예) 끼토+미개 '당근빌라 콤비'(공속+15%) · 라칠친+북거씨 '향기 나는 바구니'(회수액 2배) · 보늘+람다 '먹보 동맹'(생산 시 보늘 회복). 6C2=15관계 중 발매 시 8개.
- **타겟 우선순위**: 타워 팝업에 첫째/마지막/강한 적/마킹 우선 토글.
- **적 상성 가독화**: 적 등장 배너에 카운터 주민 얼굴 아이콘, 도감(허브 도감 연동)에 상성 기록.

### P2. 콘텐츠 볼륨 — "24스테이지 + 매주 새 판"

- **챕터 2 '젖은 골목'(장마)** 8스테이지: 기믹 — 빗길(적 이동 +20% 구간), 웅덩이(설치 불가 지대가 웨이브마다 이동), 잎사귀 우산 아이템. 신규 적: 우산 진드기(빗길에서 가속), 물풍선.
- **챕터 3 '눈 오는 골목'(겨울)** 8스테이지: 기믹 — 눈덩이(경로를 스스로 만들며 굴러옴), 얼음판(타워 공속 저하 → 배치 퍼즐), 신규 적: 눈사람 조각, 고드름. 보스: 왕눈보라.
- **스테이지 기믹 원칙**: 매 스테이지 신규 요소 1개 이상(새 적 or 새 지형 or 새 룰). "같은 판 반복" 금지.
- **하드 모드**: 챕터 클리어 시 해금, 별도 별 3개(총 별 144개) — 진화·유물 전제 밸런스.
- **주간 챌린지**: 고정 시드 + 특수 룰 1개(예: "이번 주는 미개 금지" / "도토리 2배·쾌적도 3") + 주간 리더보드. **콘텐츠 제작 없이 룰 조합으로 매주 새 판** — 라이브 비용 최소화 장치.

### P3. 성장·수집 — "+8%가 아니라 '변한다'"

- 등급 강화(현행)는 유지하되 보조 축으로 격하. 주 성장축은 **진화**(외형 교체 + 신규 능력).
- **소품 유물 12종**: 도토리 상점(세계관 장소!)에서 누적 도토리로 구매하는 패시브 장비.
  예) 왕금박 단추(시작 도토리 +40) · 진주 목걸이(끼토 범위+0.5) · 유칼립투스 잎(미스트 지속+1초) · 낡은 바구니(회수액+4) · 북gpt 단말기(웨이브 예고에 카운터 힌트 표시). 판당 3개 장착 — **출격 전 로드아웃 의사결정** 추가.
- **스킨**: 진화 A/B 외형 + 시즌 스킨(작가 굿즈와 연동). 수익화가 아니라 애착·수집 장치.
- 도감: 골칫거리·유물·진화 일러스트를 허브 도감에 등록(수집률 표시).

### P4. 판 안의 손맛 — "관전 게임 금지"

- **스킬 조준**: 북거씨 '바다' 향·라칠친 크루를 **원하는 지점에 드래그 조준**(현 전체 발동 → 조준 발동, 스킬 깊이 상승).
- **수동 줍기**: 처치 보상 일부가 필드에 도토리로 떨어지고 **탭하면 획득**(3초 후 자동). 손이 심심하지 않게 + 람다(자동 수집) 가치 재정의.
- **위기 연출**: 쾌적도 3 이하 첫 진입 시 1.5초 슬로모션 + 전 주민 경악 표정 — 긴장 피크 연출.
- **보스 기믹**: 왕꼬릿이 주기적으로 '크게 들이쉬기'(3초 무적 예고) → 그 타이밍에 스킬을 아끼는 판단 요구. 보스마다 고유 기믹 1개.
- **배속 3단**(1×/2×/3×) + 자동 다음 웨이브 토글.

### P5. 라이브 운영 — "돌아올 이유"

- 데일리: 허브 오늘의 미션(연동 완료) + 게임 내 데일리 보너스 판(첫 판 단추 조각 +1).
- **주간 챌린지 리더보드**(Firebase) — P2의 룰 조합 재사용.
- 시즌 이벤트: 분기 1회 컬래버 스테이지(솜재페 무대 방어전 — BGM 재즈 편곡, 관객 지키기).
- 리모트 컨피그: 밸런스 테이블 서버화(핫픽스), 애널리틱스(기획서 §11) 실장 — **출시 전 필수**.

## 3. 발매 기준선 (Definition of Shippable)

전 항목 충족 전에는 '정식 발매'라 부르지 않는다:

- [ ] 아트: 전용 에셋 100% (유용 0건) — 타워 대기/공격 모션, 진화 외형 12종, 적 풀 세트, 맵 테마 3종
- [ ] 콘텐츠: 24스테이지 + 하드 + 무한 + 주간 챌린지 가동
- [ ] 깊이: 진화 12종·시너지 8종·유물 12종·타겟 지정
- [ ] 온보딩: 첫 세션 완주율 80%+(내부 테스트 10인), 첫 3분 내 "오!" 모먼트 1회 이상
- [ ] 기술: 미드폰 60fps, 로드 3초, 오프라인 플레이, 세이브 클라우드 백업(닉네임 코드)
- [ ] 운영: 애널리틱스 이벤트 실장, 리모트 밸런스, 크래시 리포팅
- [ ] 사운드: 정식 BGM 3트랙(챕터별) + 효과음 폴리시(현 합성음 → 일부 정식 교체)

## 4. 로드맵 — 3개 릴리스

| 릴리스 | 기간(감) | 내용 | 게이트 |
|---|---|---|---|
| **R1 '깊이'** | 개발 집중 1차 | P1 전체(진화·시너지·타겟팅·상성 UI) + P4(조준 스킬·수동 줍기·배속3) + 전용 에셋 1차(캐릭터·적) | 내부 테스트: "조합 이야기가 나오는가" |
| **R2 '볼륨'** | 2차 | P2 챕터 2(+기믹·신규 적) + P3(유물 상점·도감) + 하드 모드 + 애널리틱스/리모트 실장 | 소프트 런칭(허브 공개), D7 리텐션 측정 |
| **R3 '라이브'** | 3차~상시 | 챕터 3 + 주간 챌린지 리더보드 + 시즌 이벤트 1회 + 스킨 | 정식 발매 선언, KPI 상향 운영 |

**우선순위 원칙 (임팩트/공수)**: 진화 시스템 > 스킬 조준 > 주간 챌린지(룰 조합) > 유물 > 챕터 2 > 시너지 > 나머지.
가장 싸고 임팩트 큰 것: **주간 챌린지** — 콘텐츠 제작 없이 리텐션 장치가 생긴다.

## 5. KPI 상향 (MVP Soft KPI → 발매 KPI)

| 지표 | MVP 목표 | 발매 목표 |
|---|---|---|
| 첫 세션 완주율(S3 도달) | 70% | 85% |
| D1 / D7 리텐션 | 측정만 | 35% / 12% |
| 평균 세션 | 8분 | 12분 |
| 1인당 누적 판수 | 5판 | 25판 |
| 조합 다양성(최다 조합 점유) | <40% | <25% (진화 후) |
| 주간 챌린지 참여율 | — | 활성 유저의 40% |

## 6. 리스크와 정면 대응

- **공수 폭발**: 진화 12종 아트+밸런스가 최대 코스트. → 진화는 **레시피 재사용**(기존 시트에 소품·색 변형 프롬프트)으로 아트 공수 절반, 밸런스는 리모트 컨피그로 출시 후 조정 전제.
- **1인 운영 지속성**: 주간 챌린지·시즌을 룰 조합/에셋 스왑으로 설계해 운영 공수를 주 1시간 이내로.
- **웹 플랫폼 한계**(수익화·푸시 없음): 발매 성공 정의를 매출이 아닌 **IP 팬덤 지표**(재방문·공유 카드 발행 수·굿즈 전환)로 명확히. 반응 검증 시 앱 래핑(Capacitor)은 R3 이후 별도 결정.
- **범위 함정**: 이 문서의 것 외에는 발매 전 추가 금지(PvP·멀티·가챠 등은 명시적 비목표).
