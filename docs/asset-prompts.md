# 당근빌라 방범대 — 나노바나나 생성 프롬프트 팩 v1.0

> ⚠ **R1 제작 기록용 보존 문서.** 실제 채택 그림체는 "2등신 치비"가 아니라 작가 원화 비율(끼토 라인업 기준)로 확정됐고, 현재 `assets/defense/`의 시트가 그 결과물. **이후 생성은 `asset-prompts-v2.md`(모션·진화·시즌 백로그)를 사용.**

> **사용법 (맥 로컬 세션에서):** 아래 순번대로 진행. 각 항목의 "첨부"를 붙이고 "프롬프트"를 그대로 복사해 생성.
> 멀티샷 컷수만큼 뽑아 가장 좋은 1장을 채택 → **채택샷은 다음 파생 생성에 반드시 첨부.**
> 결과물은 비율 그대로 `assets/defense/` 에 표기된 파일명으로 저장 (통짜 시트째 커밋 — 슬라이스·흰배경 제거는 게임 엔진/클로드가 처리).
> 전부 끝나면 커밋·푸시 → 원격 세션(이 대화)에서 이어서 슬라이스·연결.

공통 규칙: 생성마다 작가 원본 시트(`SD_시안_v1.png` 등)를 항상 첨부. 텍스트·워터마크 금지. 모델 gemini-3.1-flash-image.
